# Idea

The direction for the project and longer-term possibilities. Nothing here is a
commitment to build; shape concrete work as a [pitch](pitches/README.md) first.

## Purpose

The website of our hobby game studio. Its main job is to let visitors find
and play the games programmed at the Nationaler Zukunftstag. Each game is built
and deployed to GitHub Pages from its own repository:

- Moto Devil: <https://2raben.github.io/moto-devil/> ([source](https://github.com/2raben/moto-devil))
- Car Drive: <https://2raben.github.io/carrrgh/> ([source](https://github.com/2raben/carrrgh))

The site links to these deployments; it does not build, host, or copy the games.

## Choosing a name

"2raben" is a temporary name. Each name candidate gets its own complete version of
the site, so colleagues can compare them and decide: Schafbock Studio, Egg Settlers,
November Games, and Waldstatt Games. Once the name is chosen, the chosen version
becomes the site and the organization is renamed.

## Possibilities

Directions worth exploring later; none is a commitment:

- Sketches and screenshots of the games on their pages.
- A page for each new game the studio makes.
- News about the games' development.
